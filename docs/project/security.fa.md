# امنیت

یک آسیب‌پذیری را به‌صورت خصوصی گزارش کنید، از طریق *Report a vulnerability*
گیت‌هاب در زبانه‌ی Security ریپو - نه در یک issue عمومی.

## کتابخانه چه کاری برایتان می‌کند

* **باگ هرگز اسرارش را نمی‌گوید.** یک exception پیش‌بینی‌نشده با یک جمله‌ی
  عمومی جواب داده می‌شود؛ متنش - یک کوئری، یک مسیر، جزئیات یک نفر - در لاگ
  می‌ماند.
* **یک 404 چیزی درباره‌ی آنچه جستجو شده نمی‌گوید.** متن Django اسم مدل را
  می‌برد؛ پاسخ نه.
* **حرف‌های دیتابیس در دیتابیس می‌ماند.** یک قید بر اساس نوعش جواب داده
  می‌شود، هرگز با متنش، اسم یک ستون یا اسم یک قید.
* **کلاینت نمی‌تواند کل یک جدول را بخواند.** هر تعداد صفحه‌ای که کلاینت انتخاب
  کند سقف دارد، و هیچ سقفی خاموش‌شدنی نیست.

## چه کاری نمی‌کند

`data` همان‌طور که raise شده از سرور بیرون می‌رود: فقط چیزی را در آن بگذارید
که کسی که می‌پرسد اجازه‌ی خواندنش را دارد.
