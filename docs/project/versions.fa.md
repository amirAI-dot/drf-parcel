هر ترکیبی در CI تست می‌شود، و قدیمی‌ترین نسخه‌ی همه‌چیز با هم.

## شماره‌ی نسخه‌ها

[Semantic versioning](https://semver.org/). پیش از 1.0، یک نسخه‌ی minor -
مثل 0.2 - ممکن است آنچه از سرور بیرون می‌رود را عوض کند، و changelog آن هر
تغییر این‌چنینی را علامت می‌زند. از 1.0 به بعد، شکل قالب، کدهای خطا و
تنظیمات فقط در یک نسخه‌ی major عوض می‌شوند.

یک نسخه‌ی Django یا Python وقتی پشتیبانی خودش تمام شود از جدول بیرون می‌رود.
