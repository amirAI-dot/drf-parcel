# آموزش

فروشگاه نمونه، بخش به بخش: محصولاتی با موجودی، و سفارش‌هایی که از آن
برمی‌دارند. در پایان، هر پاسخی که می‌دهد در یک قالب است، لیست‌هایش صفحه به
صفحه می‌آیند، خطاهایش می‌گویند کلاینت چه کاری می‌تواند بکند، و اسکیمایش همه‌ی
این‌ها را می‌گوید.

| | یاد می‌گیرید |
|---|---|
| [۱. قالب](01-the-envelope.md) | پاسخ‌های یک ViewSet را در قالب بگذارید، و انتخاب کنید هر کدام چه بگوید |
| [۲. صفحه‌ها](02-pages.md) | محصولات را شماره‌ای و سفارش‌ها را با cursor صفحه‌بندی کنید، و بگذارید کلاینت تعداد را انتخاب کند |
| [۳. خطاها](03-errors.md) | هر خطا را در قالب جواب بدهید - اعتبارسنجی، خطاهای خودتان، یک باگ |
| [۴. اسکیما و زبان‌ها](04-schema-and-languages.md) | قالب را در Swagger ببینید، و به فارسی جواب بدهید |

کدی که در این صفحه‌ها می‌آید کد خود پروژه‌ی نمونه است، از همان‌جا آورده
می‌شود - پس هر خطی که این‌جا نشان داده می‌شود خطی است که تست‌هایش اجرا
می‌کنند. برای دنبال کردن، فروشگاه را اجرا کنید:

```bash
git clone https://github.com/amirAI-dot/drf-parcel
cd drf-parcel
python -m venv .venv && .venv/bin/pip install -e '.[schema]'
cd example
../.venv/bin/python manage.py migrate
../.venv/bin/python manage.py example_data
../.venv/bin/python manage.py runserver
```

جز SQLite چیزی لازم ندارد، و کسی وارد نمی‌شود: شکل پاسخ‌ها را نشان می‌دهد،
نه اینکه چه کسی اجازه دارد بپرسد.
