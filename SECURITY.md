# Security

## Reporting a vulnerability

Report it privately, through GitHub's
[Report a vulnerability](https://github.com/amirAI-dot/drf-parcel/security/advisories/new)
on this repository's Security tab - not in a public issue.

## Supported versions

The latest release receives fixes. Before 1.0, that is the latest 0.x.

## What the library does for you

* An unexpected exception answers a generic sentence; its text stays in the log.
* A 404 says nothing of what was looked for.
* A database constraint is answered by its kind, never its text.
* Every page size a client chooses has a ceiling.

`data` leaves the server as it was raised: put in it only what the person
asking may read.
